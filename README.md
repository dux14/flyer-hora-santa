# Flyer Hora Santa · Seniors Bogotá

Editor en el navegador para armar el flyer cuadrado (1024 × 1024) de la Hora Santa.

- Carga la foto de fondo (botón, arrastrar o pegar), recórtala y oscurécela.
- Ajusta texto, fuente, tamaño, espaciado y posición del título, el bloque de información y el logotipo.
- El logotipo usa la fuente **Monohipster** (Monocromo). Por su licencia de uso personal no viene incluida: cada persona carga su propio archivo .ttf con el botón **Cargar fuente del logotipo** (queda guardado en su navegador).
- **Descargar PNG** exporta la imagen final sin guías.

Uso: https://dux14.github.io/flyer-hora-santa/
